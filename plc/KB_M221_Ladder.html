Ladder M221 KALBAR PDAM

Monitoring kualitas air: pH ×2, sisa klor, turbidity. Pause dosing saat aliran sampel hilang, alarm mutu, dan data ke HMI/SCADA lewat Modbus TCP.

Arsitektur & asumsi

PLC & modul

  • TM221CE16R: 9 DI (7 terpakai), 7 DO relay (7 terpakai, tidak ada cadangan), Ethernet (Modbus TCP server ke HMI/SCADA), SL1 RS-485 (Modbus RTU master, opsional untuk TUC 5).
  • TM3AI4 (modul 1): 4 kanal 4–20 mA → %IW1.0–1.3, status %IWS1.x.
  • Analog onboard CE16R hanya 0–10 V, jadi tidak dipakai untuk sinyal 4–20 mA.

Instrumen

  • BAMa bypass fitting, 2 slot PG13.5 untuk elektroda pH, reed switch aliran sampel (maks. 42 V / 0,25 A).
  • D1Cb ×3 (pH #1, pH #2, klorin): X6 1(−)/2(+) adalah mA output aktif (maks. 450 Ω), X6 3/4 input pause (kontak kering), XR3 relai alarm.
  • TUC 5 turbidity (OEM HF Micro TOL): 4–20 mA aktif (maks. 1000 Ω) atau RS-485 Modbus, dan 2 relai alarm form C.

HMI / SCADA

  • Modbus TCP port 502. Bit %Mn = 0x n, word %MWn = 4x n (zero-based).
  • Bila driver memakai alamat 1-based, tambahkan +1.
  • Nilai proses %MW100–110, alarm %M200–219, setpoint %MW0–10.

Wiring penting

  • Semua mA output instrumen aktif: kanal TM3AI4 tanpa suplai loop 24 V.
  • Input pause D1Cb diberi tegangan internal ±6 V. Hanya sambung ke kontak relai PLC, jangan diberi 24 V.
  • Relai TUC 5 dan D1Cb ke DI 24 VDC PLC. Jangan campur 230 VAC dan SELV di terminal relai yang sama.
  • Kabel coax elektroda pH langsung ke XE1 D1Cb, pisahkan dari kabel daya.
Konfirmasi sebelum dipakai. Model PLC harus versi R (relay): TM221CE16R. Versi CE16T/CE16U (transistor) tidak bisa langsung ke input pause D1Cb. Fungsi kedua pH controller (dua titik berbeda atau redundan) adalah asumsi. Ident code kedua D1Cb pH belum dicek: harus versi mV (P 5) dengan mA output (kode 1).
Perlu diverifikasi di Machine Expert Basic: sintaks status kanal TM3 %IWS1.x, bit string %I0.0:9, pin .D/.E READ_VAR, operasi float %MF300 dan REAL_TO_INT. Peta register TUC 5 berasal dari manual HF Micro TOL 19777 (2004), jadi cocokkan dengan uji baca.
TopikAsumsi di program
Pause dosingRelai PLC ON = pause. Bila PLC mati, dosing tetap berjalan (klorinasi PDAM tidak berhenti mendadak). Set input pause D1Cb aktif saat kontak tertutup.
Aliran sampelReed switch BAMa ke PLC. Pengukuran pH/klorin valid setelah aliran stabil P_T_FLOW_ON. TUC 5 punya flow cell sendiri.
Sumber turbidityP_TU_SRC 0 = 4–20 mA (default), 1 = Modbus. TUC 5 hanya bisa mengaktifkan satu output.
Batas mutuDefault mengikuti Permenkes 2/2023: pH 6,5–8,5, kekeruhan < 3 NTU, sisa klor 0,2–1,0 mg/L (contoh). Konfirmasi dengan PDAM.
Skala analogpH 0–14, klorin 0–5 mg/L, turbidity 0–10 NTU. Harus sama dengan setting mA output tiap instrumen.
AlarmSemua alarm tidak di-latch. ACK hanya mematikan buzzer dan menghentikan kedip lampu.

Checklist komisioning

Instrumen

  • D1Cb menu 10.6: mA output 4–20 mA = pH 0–14 / klorin 0–5 mg/L, sama dengan skala TM3AI4.
  • D1Cb: input pause aktif saat kontak tertutup. Uji dengan relai %Q0.0–0.2.
  • TUC 5 menu 6.5.1: 4 mA = 0, 20 mA = 10 NTU. Menu 6.5.2: ERLV = 2 mA.
  • Lampu hijau berkedip saat valve sampel ditutup atau pause manual aktif.
  • Cek kontak reed BAMa: kontak yang tertutup saat aliran ada masuk ke %I0.0.

Uji fungsi

  • Tutup valve sampel BAMa: setelah P_T_FLOW_OFF muncul alarm aliran dan ketiga D1Cb pause.
  • Lepas kabel mA tiap kanal: alarm sinyal muncul dan nilai tidak lagi valid.
  • Simulasikan nilai di luar batas (kalibrator mA): alarm setelah P_T_ALM.
  • Bila Modbus dipakai: bandingkan %MW105 dengan display TUC 5, baca reg 30008 (model).
  • Matikan PLC: relai remote %Q0.6 jatuh dan SCADA menerima alarm.
